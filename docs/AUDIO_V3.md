# Audio v3 — тихіші теми з різними тембрами

Попередній варіант збережено: `docs/audio-archive/v2/` містить engine, score, controller, renderer і опис. Прев’ю в `public/assets/audio-v2/` не змінено. `tools/render-audio-v2.mjs` тепер відтворює саме архівний engine/score; поточний варіант генерує `tools/render-audio-v3.mjs`.

## Що змінилося

У v2 навіть щипкові ноти й дзвони утримували значну частину гучності майже всю свою тривалість. Це спільна технічна причина подібного протяжного тембру. У v3 щипки, піано й дзвони затухають відразу після короткої атаки; верхні гармоніки гаснуть швидше за основний тон. Мелодійні інструменти `reed` і `lead` не використовуються в жодній партитурі.

| Сцена | Нова палітра |
| --- | --- |
| Головна | Низький теплий фон, рідкі м’які дзвони, цілі такти без нових нот |
| Галявина | Короткі округлі щипки, бас, зрідка тихий дерев’яний стук |
| Берег | Плавний повітряний фон, негострі дзвони й окремі тихі краплі |
| Гора | Низька стримана струнна фактура, рідкі приглушені фортепіанні ноти |
| Комедія | Піцикато, легкий тридольний пульс, мінімальна перкусія |
| Бій | Тихіший ритмічний бас, короткі глушені щипки, м’які удари |

На шість 16-тактових партитур припадає 460 подій замість 1196. Мелодії мають більше пауз; друга половина фраз не підіймається у високий регістр. Відсутні безперервний шейкер, яскравий lead і наростаючий шум.

Музичну шину знижено з 1.6 до 0.9. Гучність реакцій інтерфейсу залишено окремою. Додано `audio.sound('charm')`: короткий тихий дзвіночок для талісмана.

## Виміряне порівняння

Порівняння тих самих перших 24 секунд, RMS, не LUFS і не оцінка суб’єктивного сприйняття:

| Тема | Зміна середнього рівня проти v2 |
| --- | ---: |
| Головна | −6.3 dB |
| Галявина | −11.1 dB |
| Берег | −9.2 dB |
| Гора | −6.4 dB |
| Комедія | −6.0 dB |
| Бій | −10.1 dB |

Сім нових offline-рендерів мають ненульовий сигнал, жодного NaN/Infinity і жодного перевантаженого семплу. Піки музики — 0.069–0.151. Дані: `public/assets/audio-v3/render-checks.json`.

Прев’ю: `assets/audio-v3/{title,clearing,river,mountain,comedy,battle}-preview.wav`, кожне 24 с. `effects-preview.wav` — 17 с, останнім звучить charm. Це WAV 22.05 kHz mono для швидкого порівняння; гра використовує той самий синтезатор наживо зі стереопозиціями.

## Межі перевірки

Доступні засоби перевіряють декодування, сигнал і роботу браузера; засобу модельного слухового прослуховування не знайдено. Тому тут не стверджується, що нову музику вже прослухано або що вона гарантовано усуває втому. М’якше аранжування — реалізоване дизайнерське рішення; остаточне сприйняття треба порівняти за прев’ю.

API не змінено: `unlock`, `setMuted`, `setMode`, `sound`, `destroy`, `muted`. Перевірено всі режими, mute/unmute, throttle друку, повторний unlock і від’єднання джерел після destroy. Всі шість партитур коректно повторюються через 16 тактів.
