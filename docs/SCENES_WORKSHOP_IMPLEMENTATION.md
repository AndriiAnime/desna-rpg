# Майстерня сцен, 26 жовтня 2026

Локальна сторінка: `scenes.html`. Тексти та правила — у [storyboard](SCENES_STORYBOARD.md). Нові сцени навмисно зібрані окремо для огляду композиції, реплік і темпу перед підключенням до основної гри.

## Що можна перевірити

- 12 розділів українською й англійською. Перехід по розділах дає спорядження, яке було б отримане до відповідного етапу; пряме посилання `?chapter=upyr` поводиться так само.
- Великий Лакі, швидкий друк, рух тільки під час репліки, комічні схеми, затемнений ліс із легким коливанням нижнього шару.
- Три плашки перед боєм: статична геометрія, анімована текстура й одна сфера. Ім’я відокремлене, основний текст Roboto без курсиву.
- Навчальний бій: дозволені лише голова → захист корпусу. Далі Блуд, Русалка та Упир із двома фазами.
- Суперблок, удар хвостом і повне лікування — раз за бій. Поразка створює нову спробу з новими зарядами. Дві фази Упиря використовують спільні заряди. У редакції 02 лікування миттєво повертає 1 HP → 3 HP без витрати ходу: герой потім обирає атаку та захист.
- Загадки з підказкою після правильної відповіді. Уже розгадані зберігаються при перемиканні мови й діалогового оформлення в межах відкритої майстерні; повтор розділу починає загадки заново.
- Фінал, дві ілюстрації титрів, натяк на продовження. Відкриття NG+ і бібліотеки записується окремим ключем `desna.scene-workshop.completed.v1`.
- NG+ видає всі здібності й гирю, змінює репліки та пропускає навчальний бій, квест коваля й повторне відкидання бар’єром. Книгознавча частина бібліотеки відділена від авторської інтерпретації; джерело Упиря поки не підтверджене.

## Межі прототипу

Нові мапи — ілюстровані сцени з анімованими накладками. У майстерні введення руху перевіряє подію першого кроку/підходу; тут немає нової повної сітки прохідності. Послідовність коваля й Русалки показана як постановочні вставки: вільний вибір порядку NPC, повторні мовчазні удари хвостом, рух супутника по реальному маршруту й переходи між трьома Phaser-мапами ще належить інтегрувати. Поточна ігрова галявина лишається окремим робочим проходом.

Анімація діалогового фону — CSS-текстура та геометрія, а не відео. Рух дерев — дуже слабке зміщення/нахил замаскованого нижнього шару зображення; це не окрема покадрова анімація гілок. Усі ці ефекти вимикаються при системному `prefers-reduced-motion`.

## Перевірка

- `npm test`: 104 тести, включно з 11 новими перевірками правил кампанії та цілісності двомовного контенту.
- `npm run build`: усі шість сторінок збираються; залишається попереднє повідомлення про великий пакет Phaser.
- Окремий браузер пройшов усі 12 розділів і 4 бої, відкрив бібліотеку й NG+, перевірив пряме посилання з належним спорядженням. Для проходження довгі паузи прискорено у тестовому браузері; скріншоти композиції знято з реальними таймінгами.
- UI Kit перевірено у двох мовах на desktop і 390×844. Майстерня сцен також перевірена у desktop та 390×844; горизонтального переповнення немає.
- Результати: `docs/qa/scenes-v1/flow-results.json`, знімки поруч. Джерела згенерованих асетів і перевірки копіювання: `docs/concepts/scenes-v1/manifest.json`.

## Збереження та наступна інтеграція

Чекпойнт до цього етапу: `checkpoint/ui-kit-before-scenes-20261026` → `ae2aa56`. Робоча гілка — `experiment/immersive-ui`. GitHub Pages у цьому етапі не оновлювались.

Після вибору плашки та затвердження реплік перенести спільний програвач діалогів у основний маршрут Start → intro → map. Далі підключати по одній локації з її навігацією й квестовими прапорцями. Це дозволить окремо перевіряти композицію сцени та реальну поведінку на мапі.
