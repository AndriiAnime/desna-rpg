**26.10 — поточна редакція v3:** [грати українською](http://127.0.0.1:5174/play.html?lang=uk) · [play in English](http://127.0.0.1:5174/play.html?lang=en) · [майстерня сцен](http://127.0.0.1:5174/scenes.html?lang=uk) · [UI Kit](http://127.0.0.1:5174/ui-lab.html?font=heritage&feedback=reference).

`play.html` відкриває меню й проходження без редакторських панелей. `scenes.html` залишає вибір розділів, порівняння спрайтів і прискорене завершення тестового бою. Є рух до персонажів по дозволених маршрутах, чотири бої, одноразові за бій здібності, фінал, бібліотека та NG+. Шість музичних тем отримали м’якші різні тембри й нижчу гучність; попередній звук збережено.

Пройшли **121/121 тестів**; також перевірено проходження 12 розділів українською й англійською, маршрути до персонажів, меню, бібліотеку та NG+. Браузерний прохід використовує прискорення бою в майстерні; бойові правила перевіряються окремо. [Опис v3 та межі перевірки](docs/SCENES_V3.md) · [звіт проходження](docs/qa/scenes-v3/flow-results.json) · [аудіо v3](docs/AUDIO_V3.md).

**Публікація v3 ще очікує виконання.** Заплановані адреси: [гра — /alternative/play.html](https://andriianime.github.io/desna-rpg/alternative/play.html) · [майстерня — /alternative/scenes.html](https://andriianime.github.io/desna-rpg/alternative/scenes.html). Наявність цих посилань не підтверджує, що нова редакція вже доступна онлайн. Базова Alpha 2 має залишитися за початковою адресою.

## Архівний опис базової Alpha 2

Нижче — успадкований опис початкової гри. Його обмеження та статуси стосуються Alpha 2; актуальний стан альтернативної редакції наведено вище та в [SCENES_V3.md](docs/SCENES_V3.md).

Маленька браузерна RPG за мотивами фольклору Чернігівського Полісся. Розробляємо окремими погодженими чанками; поточна версія — **Alpha 2, стежка → Лакі → розмова з Блудом → повний бій**.

## Запуск

Потрібен Node.js 22.12+; `.nvmrc` обирає Node 22.

```sh
nvm use
npm ci
npm run dev
```

Відкрий адресу, яку надрукує Vite. `npm test` перевіряє рух, взаємодії, спрайти й бойові правила; `npm run build` створює статичний `dist/`; `npm run preview` показує саме зібрану версію.

## Що вже працює

- Старт, сюжетний вступ і його повторний перегляд у нотатках.
- Мапа А v8: ширші стежки й міст, збільшений камінь; тільки герой і Блуд біля мосту. Оригінал v6 збережено.
- Рух у 8 напрямках: стрілки, WASD, діагональний D-pad або натискання на стежку / ворога. Швидкість однакова — 170,18 px/s (+30% до попередніх 130,91 px/s).
- Ручний рух ковзає вздовж похилих меж стежки й каменя; непрохідні ділянки залишаються закритими.
- `route-editor.html` показує фактичну дозволену зону, дає намалювати правки й експортувати їх у PNG / JSON. Дев’ять штрихів Андрія від 20 жовтня вже перенесені в геометрію гри; чернетка збережена для порівняння.
- Герой використовує ходьбу v2 з окремою правкою NE v3; фаза кроку залежить від відстані; частоту анімації зменшено на 30% без зміни швидкості пересування. Після зупинки випадково обирає один із двох спокійних idle, через 5 с бездіяльності починає тупотіти ногою. Новий ввід скидає очікування. У спрайтів є контактні тіні.
- Камінь перекриває короткий маршрут; нижня петля дає обхід. Трава, ліс і вода непрохідні.
- Масштаб персонажів 1,65×; базове наближення камери 1,5×. На вузьких екранах показуємо меншу ділянку світу. Камера слідує за героєм.
- Доступна ціль кліку позначена пульсуючим колом до прибуття/заміни, заборонена — коротким червоним знаком. Курсор стає мечем над ворогом.
- Камінь спершу має курсор питання; клік веде до дозволеної точки поруч. Лакі один раз каже «Тут не пройти.» і залишається на камені: сидить спокійно, кожні 10 с один раз озирається. Діалоги й паузи зупиняють idle-таймери. Чібі-портрет показаний у стилізованому зеленому вікні.
- Блуд на старті спокійний. Починає кликати в радіусі 127,82 px — останніх 30% початкової прямої відстані від героя. При відході є запас 12 px проти частого перемикання станів.
- Підхід до Блуда запускає двосекундний blur/twist, розмову до пояса й перехід за 500 мс до бою на повний зріст. Фон — обраний «Похмурий день»; Блуд на 20% вищий за героя.
- Бій: 3 HP, спочатку зона удару, потім зона захисту; другий вибір запускає хід без окремого підтвердження. Підписи дій видимі 1,8 с до ударів. Перемога відкриває міст; поразка дозволяє нову спробу.
- Оригінальна синтезована музика поля й бою, ефекти та кнопка динаміка. Вибір вимкнення зберігається локально.
- «Почати заново» скидає проходження й одноразову підказку. `map-sprites.html` зберігає окрему майстерню попередніх спрайтів.
- Під основною грою — порівняння фонів, трьох кадрувань і альтернативних idle-анімацій. Тестові бої не змінюють проходження; рух мапою під час тесту призупинений.

**Магазину, загадок і збереження проходження ще немає.** Нове комедійне інтро Lucky записане для майбутнього чанка й ще не замінює поточний вступ. Новий арт — кандидати для перегляду в грі.

## Як читати код

Головний екран використовує останній PS2-арт із героями та місцем під назву. Основний варіант — **«Невідспівані: Прах над Десною»**; кнопки внизу перемикають його на **«Друге народження богів: Прах над Десною»**. Пряме посилання на альтернативу: `/?title=rebirth` (на GitHub Pages — `/desna-rpg/?title=rebirth`). Кнопка «Почати гру» відкриває наявний вступ і карту. Реалізація — `src/title-screen.js` та `src/title-screen.css`.

| Файл | Що робить |
| --- | --- |
| `src/content/clearing.js` | Геометрія кам'яних стежок, каменя, старту й ворога у координатах мапи |
| `src/content/clearing-navigation.js` | Намальована Андрієм ширша зона руху; центральна зелень залишається непрохідною |
| `src/domain/polygon-navigation.js` | Перевірка стопи й усього кроку всередині контуру, нормаль для ковзання |
| `src/domain/clearing.js` | Чисті правила кроку, колізій, зустрічі та пошуку маршруту |
| `src/domain/walk-cycle.js`, `sprite-layout.js` | Фаза кроку за відстанню та точні межі/опори кадрів |
| `src/domain/idle-behavior.js` | Спокійні стани, таймери героя й Лакі та тривалість кадрів |
| `src/route-editor.js` | Полотно для перевірки прохідності й ручних правок маршруту |
| `src/content/story.js` | Поточні оповідач і вступна історія |
| `src/input.js` | Клавіатура й D-pad; повтор при утриманні та скидання вводу |
| `src/main.js` | Стан проходження, черга маршруту, діалоги й блокування руху |
| `src/scenes/ClearingScene.js` | Мапа, варіанти анімації, тіні, Лакі, позначка цілі, камера та координати кліку |
| `src/domain/battle.js`, `src/battle.js` | Чисті бойові правила та окремий екран бою |
| `src/content/blud-encounter.js` | Прототипні репліки перед боєм українською й англійською |
| `src/battle-icons.js`, `src/battle-icons.css` | Піксельні значки вибору удару/захисту та їхні анімації |
| `src/review-workshop.js` | Порівняння фонів, кадрувань і idle; ізольовані тестові бої |
| `src/audio.js`, `src/battle-transition.js` | Музика/ефекти й перехід до бою |
| `index.html`, `src/style.css` | Старт, керування, нотатки, діалог і адаптивний viewport |

Використовуємо **Phaser 4.2.1 + Vite 8.3.4 + JavaScript/HTML/CSS**, без Vue чи фізичного рушія. Пошук маршруту та ручний рух проходять через ті самі перевірки прохідності. Phaser показує лише дозволені позиції. Історичні `world.js` / `WorldScene.js` та їхні тести збережено, але головна сторінка вже використовує нову галявину. Відносний `base: './'` готує збірку до майбутнього розміщення у вкладеній папці GitHub Pages.
