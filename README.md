# Прах над Десною · Alpha 2

A browser RPG prototype inspired by Ukrainian folklore. Built with Phaser and Vite.

## Play

https://AndriiAnime.github.io/desna-rpg/

## Develop

Requires Node.js 22.12+ (Node 22 LTS).

```sh
npm ci
npm run dev
npm test
npm run build
```

Move with WASD, arrow keys, the touch direction pad, or by tapping a path. The rock blocks the short route; Lucky gives a hint and Blud guards the bridge.

Alpha 2 includes random calm hero idle, foot tapping after 5 seconds, and Lucky's curious glance every 10 seconds. Walking animation is 30% slower while movement remains 170.18 px/s.

GitHub Pages publishes the production build from `dist/`. Current mobile testing targets modern Safari and Chrome.

This is a prototype with generated artwork and temporary reference-derived UI/sprite assets; asset ownership is not implied by this source repository.
